# glottos — вертикальный TikTok-мокап (RU→FR)

Самоиграющий 9:16 мокап «говорение = уровень» в формате вирусного langtok:
**хук → агент отвечает НЕПРАВИЛЬНО → программа не пропускает (✗) → исправляется → ✓ → LEVEL UP → финал + CTA**.

## Файлы
- `scene.html` — анимация (тайминги/тексты/боли — всё здесь). Открывается и в обычном Chrome.
- `make.mjs` — пайплайн сборки: espeak-ng (голоса) → ffmpeg (SFX + бит) → mix → Playwright рендер 1080×1920 → mux в mp4.

## Сборка
```bash
cd glottos-auto
node tiktok/make.mjs        # → ../out/glottos_tiktok_ru_fr.mp4 (1080x1920, H.264+AAC, ~25s)
```
Готовый ролик раздаётся контейнером `glottos-files` → http://localhost:8093/glottos_tiktok_ru_fr.mp4

### Зависимости контейнера (теряются при ребилде образа — поставить заново)
```bash
# в claude-контейнере (узнать имя: cat /etc/hostname; НЕ docker ps|head -1)
docker exec -u 0 "$(cat /etc/hostname)" sh -c \
  'apt-get update && apt-get install -y espeak-ng fonts-noto-color-emoji && fc-cache -f'
```
- `espeak-ng` — синтез голоса (FR реплики + RU хук/аутро). Без него `make.mjs` падает на espeak.
- `fonts-noto-color-emoji` — иначе эмодзи 🔥🇫🇷☕🚕🤝 рендерятся «тофу»-квадратами.

Звук/ответы в мокапе **фейковые** — цель «посмотреть, как смотрится». В прод заменить на реальный TTS
(ElevenLabs/Azure) + лицензионный трендовый трек, ответы — на настоящий STT.

## Почему НЕ записали залогиненные уроки (speaking-дрилл)
Хотели снять gated-вкладку 🔊 **Аудио-практика** (speaking) из реального `courses.glottos.com` под
аккаунтом владельца. **Заблокировало то, что у glottos нет переносимой сессии:**

1. **В куках glottos сессии нет.** Полный cookie-экспорт домена содержал только `g_state` (Google GSI)
   и `..._posthog` (аналитика). Никакого session-cookie/JWT.
2. **В localStorage токена тоже нет.** `gl.v1.state` существует, но внутри только анонимный
   `user.id` (UUID) + языковые префы + пустой `courses`. Ни токена, ни email.
3. **Email виден только в PostHog** (`distinct_id: …@gmail.com`, `user_state: identified`) — это
   аналитика, не авторизация.
4. **Вывод:** glottos логинит через **тихий Google Sign-In (GSI silent)** на каждой загрузке, опираясь
   на активную сессию Google в браузере. Отдельного glottos-токена, который можно перенести в Playwright,
   **не существует**.
5. Единственный способ «залогинить» headless-агента — затащить **полную сессию Google** (мастер-куки
   `SID`/`__Secure-1PSID`). **Не делаем:** вход из дата-центра по этим кукам Google почти гарантированно
   флагает/лочит аккаунт, плюс это ключ ко всей почте/диску. Не стоит ролика.

**Как всё же получить speaking-кадры (без риска):** владелец сам делает 10–20-сек запись экрана
🔊 Аудио-практики в своём залогиненном браузере (OBS/Win+G/телефон) и присылает клип — он монтируется
в ролик. Креды остаются у владельца.
